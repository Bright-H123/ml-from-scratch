## 1. 什么是机器学习

Arthur Samuel 的定义：不用显式编程就让计算机具备学习能力。Tom Mitchell 的定义更好用：

> 程序从**经验 E** 中学习**任务 T**，用**度量 P** 衡量表现；如果 P 随 E 增加而提升，就说它在学习。

做项目时这三样必须先写清楚。比如"预测双人协作中的出界事件"：T = 二分类，E = 历史轨迹片段+标签，P = F1（不是准确率，因为出界很稀少）。**如果 P 定不清楚，后面所有工作都没有方向。**

## 2. 监督学习 vs 无监督学习

**监督学习**：给的数据是 (x, y) 成对的，学 x → y 的映射。
- 回归：y 是连续数值，输出有无穷多种可能（房价、温度）
- 分类：y 是有限类别（垃圾邮件是/否、肿瘤良/恶性）

分界不在"输出是不是数字"，而在**输出的可能取值是不是有限个**。用 1/2/3 编码三个类别仍然是分类。

**无监督学习**：只有 x 没有 y，让算法自己找结构。
- 聚类（K-means）、异常检测、降维（PCA）

## 3. 线性回归模型

单变量：

```
f_{w,b}(x) = w·x + b
```

- `w` 斜率，`b` 截距，合称**参数**（parameter / weight / coefficient）
- 训练集里第 i 个样本记作 `(x⁽ⁱ⁾, y⁽ⁱ⁾)`，共 m 个
- `ŷ⁽ⁱ⁾ = f(x⁽ⁱ⁾)` 是预测值，`y⁽ⁱ⁾` 是真值。**这两个必须分清**，代价函数就是衡量它们的差。

## 4. 代价函数

```
J(w,b) = (1/2m) · Σᵢ (f(x⁽ⁱ⁾) − y⁽ⁱ⁾)²
```

三个细节：

1. **为什么平方**：让正负误差不抵消，且大误差被放大得更狠（离群点影响大——这也是平方误差的弱点）。
2. **为什么除 m**：不除的话样本越多代价越大，不同大小的数据集之间没法比。
3. **为什么再除 2**：纯粹是为了求导后把平方掉下来的 2 约掉，梯度式子干净。它不改变最优解位置（乘常数不改变 argmin）。

### 代价函数长什么样

- 固定 b=0，J 对 w 是一条**开口向上的抛物线**（因为 J 是 w 的二次函数）。
- w、b 都变，J(w,b) 是一个**碗状曲面**（凸函数），画等高线是一圈圈同心椭圆。
- **关键性质：线性回归的平方误差代价是凸的，只有一个全局最小值，没有局部最小值。** 所以梯度下降只要学习率合适就一定收敛到全局最优。这个性质到逻辑回归用平方误差时就没了（见 C1W3）。

## 5. 梯度下降

### 算法

重复直到收敛：

```
tmp_w = w − α · ∂J/∂w
tmp_b = b − α · ∂J/∂b
w = tmp_w
b = tmp_b
```

**必须同时更新**（simultaneous update）。写成
```
w = w − α·∂J/∂w
b = b − α·∂J/∂b   ← 这里的 ∂J/∂b 用的是新 w
```
就错了：第二行的导数是在已经更新过的 w 上算的，这不是梯度下降，是另一个算法（可能也能work，但不是这个）。代码里用 `dj_dw, dj_db = compute_gradient(...)` 一次算完再更新，天然就是同时的。

### 直觉

`∂J/∂w` 是当前点切线斜率：
- 斜率为正 → w 减小 → 往左走（朝低处）
- 斜率为负 → w 增大 → 往右走

α 永远是正数，方向由导数符号决定。

### 学习率 α

- α **太小**：能到，但慢得离谱
- α **太大**：一步跨过最低点，可能来回震荡甚至发散（J 越来越大）
- 到达局部最小时导数为 0，更新量为 0，自动停下——**不需要手动减小 α**。而且越接近最小点，导数越小，步子自动变小。

诊断方法：**画 J 对迭代次数的曲线**。正确的运行应该每一步都下降。只要看到上升，就是 α 太大。代码里 `gradient_descent` 返回 `cost_history` 就是为这个。

### 导数推导

```
J = (1/2m) Σ (w·x⁽ⁱ⁾ + b − y⁽ⁱ⁾)²

∂J/∂w = (1/2m) Σ 2·(w·x⁽ⁱ⁾ + b − y⁽ⁱ⁾)·x⁽ⁱ⁾ = (1/m) Σ (f(x⁽ⁱ⁾) − y⁽ⁱ⁾)·x⁽ⁱ⁾
∂J/∂b = (1/2m) Σ 2·(w·x⁽ⁱ⁾ + b − y⁽ⁱ⁾)·1   = (1/m) Σ (f(x⁽ⁱ⁾) − y⁽ⁱ⁾)
```

这里能看到那个 1/2 的作用了。

### "Batch" 的含义

Batch gradient descent = 每一步都用**全部 m 个训练样本**算梯度。课程里用的都是这种。还有 mini-batch / stochastic 版本（每步只用一部分），本课不展开，但 Adam（C2W2）会用到相关思想。

## 6. 常见坑

| 坑 | 后果 | 怎么发现 |
|---|---|---|
| 没有同时更新 w 和 b | 收敛行为异常 | 代码审查；先算完全部梯度再更新 |
| α 太大 | J 震荡/发散 | 画 cost history |
| 把 J 的 1/2 忘了，或梯度里没除 m | 相当于改变了有效学习率 | 数值梯度检验（见下） |
| 用 test 集的数据去调 α | 测试指标虚高 | 流程约束，test 只碰一次 |

### 数值梯度检验（自己写梯度时必做）

```python
eps = 1e-6
numeric = (J(w + eps) - J(w - eps)) / (2*eps)
assert abs(numeric - analytic) < 1e-7
```

本仓库的 `tests/test_linear_regression.py` 就是这么验的，实测差在 1e-9 量级。

## 7. 代码对照

```python
from mlkit import datasets, linear_regression as lr

X, y = datasets.house_prices()
w, b, hist = lr.gradient_descent(X, y, alpha=1e-7, num_iters=1000)   # 未缩放，alpha 必须极小
w_ne, b_ne = lr.normal_equation(X, y)                                 # 闭式解，一步到位
```

未缩放时 α 只能取 1e-7 这个量级，这直接引出下一周的特征缩放。
