## 1. 为什么线性回归做不了分类

拿"肿瘤大小 → 恶性(1)/良性(0)"举例。用线性回归拟合再取 0.5 阈值，看起来能用。但只要**加进一个尺寸特别大的恶性样本**（在图右边远处），最小二乘为了照顾这个点会把整条直线压平，0.5 的交点右移，原本判对的样本变成判错。

**分类问题上，增加一个显然正确的样本反而让模型变差——这说明代价函数选错了。** 另外线性回归输出可以是 -3 或 1.7，而我们要的是概率。

## 2. 逻辑回归

### Sigmoid

```
g(z) = 1 / (1 + e^(−z)),    g: ℝ → (0,1)
```

- z → +∞ 时 g → 1；z → −∞ 时 g → 0；z = 0 时 g = 0.5
- 关键导数：`g'(z) = g(z)·(1 − g(z))`（后面反向传播要用）

模型：

```
f(x) = g(w·x + b) = 1 / (1 + e^(−(w·x+b)))
```

**解读为概率**：`f(x) = P(y=1 | x; w,b)`。所以 f(x)=0.7 意思是"有 70% 概率是 1"，同时 P(y=0)=0.3，两者和为 1。

### 数值稳定

`e^(-z)` 在 z 很负时会溢出。代码里对 z 做了 `clip(-500, 500)`——在这个范围外 sigmoid 已经饱和到 0 或 1（float64 精度下），裁剪不改变任何答案，只是消掉 overflow warning。

## 3. 决策边界

预测 1 当且仅当 `f(x) ≥ 0.5`，而 `g(z) ≥ 0.5 ⟺ z ≥ 0`。所以：

> **决策边界就是 `w·x + b = 0` 这个超平面。**

- 两个特征时是一条直线：`w₀x₀ + w₁x₁ + b = 0`
- 加入多项式特征后边界可以是圆、椭圆、任意复杂形状。例如 `z = x₁² + x₂² − 1`，边界就是单位圆。

**这一点很重要**：逻辑回归本身只能画直线边界，但对**工程出来的特征**它是线性的，所以喂多项式特征就能得到弯曲边界。这也正是它容易过拟合的来源。

## 4. 代价函数：为什么不是平方误差

把 `f = sigmoid(...)` 代进平方误差，J(w,b) 变成**非凸**的——曲面上有很多坑，梯度下降可能停在局部最小值。

### 单样本损失

```
L(f, y) = −log(f)        if y = 1
        = −log(1 − f)    if y = 0
```

直觉：
- y=1 时，f→1 则 L→0（预测对了，不罚）；f→0 则 L→∞（**信誓旦旦说是 0，结果是 1，罚到无穷大**）
- y=0 时对称

这个"罚到无穷"是交叉熵的灵魂：它对**自信的错误**惩罚极重，而平方误差最多罚 1。

### 合并成一行

```
L(f, y) = −y·log(f) − (1−y)·log(1−f)
```

y 只能取 0 或 1，所以两项里总有一项被乘 0 消掉，这不是近似，是完全等价的写法。

### 总代价

```
J(w,b) = (1/m) Σᵢ [ −y⁽ⁱ⁾log(f(x⁽ⁱ⁾)) − (1−y⁽ⁱ⁾)log(1−f(x⁽ⁱ⁾)) ]
```

注意**没有 1/2**（平方误差才需要那个 1/2 去约导数的 2）。

这个 J 是凸的。它来自最大似然估计：假设 y|x ~ Bernoulli(f(x))，对数似然取负就是它。

## 5. 梯度：和线性回归"形式一样"

```
∂J/∂wⱼ = (1/m) Σᵢ (f(x⁽ⁱ⁾) − y⁽ⁱ⁾)·xⱼ⁽ⁱ⁾
∂J/∂b  = (1/m) Σᵢ (f(x⁽ⁱ⁾) − y⁽ⁱ⁾)
```

**形式一样，但不是同一个算法**——`f` 的定义不同（一个是 `w·x+b`，一个是 `sigmoid(w·x+b)`），算出来的数完全不同。

### 为什么会这么巧

不是巧合。求导时：

```
∂L/∂f = −y/f + (1−y)/(1−f) = (f − y) / (f(1−f))
∂f/∂z = f(1−f)                              ← sigmoid 的导数
∂L/∂z = ∂L/∂f · ∂f/∂z = f − y               ← 分母被约掉了
```

sigmoid 的导数恰好等于交叉熵求导后的分母。这是"配对"设计的结果：softmax + 交叉熵也有同样性质（C2W2）。

## 6. 过拟合与欠拟合

| | 训练集表现 | 泛化 | 术语 |
|---|---|---|---|
| 模型太简单 | 差 | 差 | **欠拟合 / 高偏差 (high bias)** |
| 模型刚好 | 好 | 好 | just right / generalization |
| 模型太复杂 | 极好（可能 0 误差） | 差 | **过拟合 / 高方差 (high variance)** |

"高偏差"直觉：算法带着某种先入之见（"房价一定是线性的"），不管数据怎么说都不改。
"高方差"直觉：换一批稍微不同的训练数据，就学出一个截然不同的模型。

### 三种解法

1. **收集更多数据** —— 最直接有效，但常常做不到
2. **减少特征数** —— 特征选择；缺点是可能扔掉有用信息
3. **正则化** —— ★保留所有特征，但把 w 压小

## 7. 正则化

```
J(w,b) = 原代价 + (λ/2m) Σⱼ wⱼ²
```

### 为什么有效

过拟合的模型往往有**很大的权重**（为了穿过每一个点，函数必须剧烈扭动，扭动就需要大 w）。加上惩罚项后，模型必须在"拟合数据"和"保持 w 小"之间权衡，自动变平滑。

### 三个细节

1. **不正则化 b**。b 只是整体上下平移，与模型复杂度无关。惩罚它实践上没帮助。
2. **除以 2m**：跟主项同量纲，这样 λ 的合适取值不随 m 变化太多。
3. **λ 的两个极端**：
   - λ = 0 → 完全不正则化 → 过拟合
   - λ 极大（比如 10¹⁰）→ 所有 w 被压到接近 0 → `f(x) ≈ b` → 一条水平线 → 欠拟合

### 梯度

```
∂J/∂wⱼ = (1/m) Σ (f − y)xⱼ + (λ/m)·wⱼ
∂J/∂b  = (1/m) Σ (f − y)                    ← b 没有额外项
```

更新式重排一下很有启发：

```
wⱼ := wⱼ − α[(1/m)Σ(f−y)xⱼ + (λ/m)wⱼ]
    = wⱼ(1 − αλ/m) − α·(1/m)Σ(f−y)xⱼ
       └──────────┘
     每步先把 w 缩小一点点（比如 ×0.9998），再走原来那一步
```

这就是**权重衰减 (weight decay)** 这个名字的由来。

### 线性回归和逻辑回归的正则化式子完全一样

梯度形式同样一样，只有 f 的定义不同。所以 `mlkit` 里两个模块的 `compute_gradient` 长得几乎一模一样。

## 8. λ 怎么选

**不能用训练集选**（λ=0 训练误差总是最小），**也不能用测试集选**（那样测试指标不再是无偏估计）。

正确做法是用**交叉验证集**：把 λ 取 `0, 0.01, 0.02, 0.04, …, 10`（大约每次×2），各训一个模型，选 J_cv 最小的。完整流程见 C2W3 笔记。

## 9. 代码对照

```python
from mlkit import datasets, logistic_regression as lg, metrics

X, y = datasets.two_class_2d(m=400, seed=2)
clf = lg.LogisticRegression(alpha=0.5, num_iters=8000, lambda_=0.0).fit(X, y)

print(clf.w, clf.b)                     # 和 sklearn(C=1e6) 的结果一致到 3 位小数
print(metrics.accuracy(y, clf.predict(X)))

# 调阈值换精确率/召回率
clf.threshold = 0.8                     # 更保守：精确率↑ 召回率↓
```

阈值不是模型的一部分，是**部署时的决策**。改阈值不需要重新训练。
